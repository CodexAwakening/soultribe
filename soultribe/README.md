# Soul Tribe

A sacred space for spiritual seekers to find their tribe — authentic friendships, conscious relationships, meditation partners, and a community that honors your journey.

## Getting Started

First, run the development server:

```bash
cd soultribe
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Next.js 16** (App Router)
- **Tailwind CSS 4**
- **Framer Motion** (animations)
- **Phosphor Icons**

## Deploy

Optimized for Netlify deployment. Connect your GitHub repo and deploy automatically.
